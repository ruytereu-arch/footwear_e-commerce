# SyntaxWear - Footwear E-commerce

Este projeto consiste em uma landing page responsiva para um e-commerce de calçados, desenvolvida com foco em arquitetura de componentes CSS e design moderno.

## Descrição

A SyntaxWear é uma interface front-end projetada para oferecer uma experiência de navegação fluida em diferentes dispositivos. O projeto demonstra a aplicação de conceitos avançados de CSS, como sistemas de grid complexos e layout flexível, sem a necessidade de frameworks externos.

## Tecnologias Utilizadas

- **HTML5**: Estruturação semântica de dados.
- **CSS3**:
  - CSS Grid e Flexbox para layouts responsivos.
  - Custom Properties (Variáveis CSS) para gestão de design system.
  - Metodologia de organização por componentes.
  - Design Responsivo com Media Queries.
- **Tipografia**: Google Fonts (Ubuntu).

## Principais Funcionalidades

- Interface totalmente responsiva (Desktop, Tablet e Mobile).
- Sistema de navegação mobile via menu lateral.
- Grid de produtos dinâmico com áreas de destaque.
- Seções de categorias com efeitos de interação (hover).
- Rodapé institucional completo com formulário de newsletter.

## Estrutura do Projeto

- \`index.html\`: Documento principal.
- \`css/\`: Diretório de estilos.
  - \`variables.css\`: Definições de cores e fontes globais.
  - \`reset.css\`: Normalização de estilos entre navegadores.
  - \`base.css\`: Estilos de elementos base e utilitários.
  - \`components/\`: Estilos modulares (Header, Hero, Product Grid, Footer).
- \`images/\`: Repositório de ativos visuais e ícones.

## Execução Local

Para visualizar o projeto localmente:

1. Clone este repositório.
2. Abra o arquivo \`index.html\` em um navegador web.
